# Riso Processor · Image + Motion + Poster

浏览器本地图片、静音短视频与拼图海报工具。保留原版薄荷绿、黑白参数面板与灰色画布。

## 运行

Node.js 20+，`npm install`，`npm run dev`。生产构建 `npm run build`，输出 `dist/`，相对资源路径可部署到子目录。无需 API Key。

## 功能

- 六套共享纸墨的风格预设及当前素材效果缩略图：青粉刊物、青黄叠印、粉黄印样、青粉柔网、青墨摄影、黑墨纸本。
- 细颗粒、柔和网点、清晰网点三种渲染；柔网保留可见颗粒，降低边缘硬度、对比及套色偏移。墨色、叠印浓度、对比、网点、底图、套印偏移可调整。
- 图片/视频导入，示例素材，原图效果对照，参数撤销（最多 30 步）与恢复默认；参数保存到本地浏览器。
- 图片/视频当前帧导出 PNG，最长边 2400 px，不放大小图，始终不含对比界面。
- 视频预览与定位；截取最长 15 秒的静音片段，最长边 640 px，目标 12 fps，性能受设备影响。
- 优先浏览器原生 H.264 MP4，其次 WebM。不能承诺所有手机浏览器都支持编码；不支持时给出提示。
- 视频导出可取消，切到后台自动取消，不交付半成品。完成后显示下载链接，避免浏览器阻止自动下载。
- 图片最多 5000 万像素、文件最多 250 MB；失败保留当前素材。

视频不保留原声；不支持批处理、云端处理、后台导出或专业印刷色彩校准。效果为屏幕模拟。

## 海报拼图（2026-11-18）

- `#poster` 直接进入拼图；5 种版式：套印刊物、封面研究、双图对页、四格印样、错位拼贴。
- 默认刊物版：细黑大字跨栏、四栏可编辑正文、青粉黄透明叠色、细纸纹；正文以独立一行 `---` 分栏。
- 一次导入多张照片，素材库最多 6 张；每张最多 50 MB / 5000 万像素，内部缩至最长边 2000 px 以控制内存。
- 逐格替换、拖动裁切、1–3 倍缩放、双色 / 单墨 / 原图；可把视频当前帧加入拼图。
- 标题、刊头、署名、期号、副标题、正文均可改；刊物照片浓度、第三图形专色、几何图形及套准标记可调。
- 3:4 / 4:5 / 1:1 画幅，PNG 最长边 2400 px；预览与导出使用同一编排函数，选框仅在界面显示。
- 图像、视频与海报共用纸色、墨色、预设及叠印浓度，切换模式实时同步；海报的第三图形专色独立。标签切换保留本次拼图，刷新页面会重置拼图；纸墨参数保存在浏览器。
- 拼图目前只导出静态 PNG，不导出拼图动画。

验证：真实浏览器多图导入、无效图片保留当前内容、拖动取景、字体与中文标题、画幅切换；下载 1800×2400 与 1920×2400 PNG 检查。390×844 视口下无横向溢出，批量导入与 PNG 导出通过。原视频流程回归导出 2 秒 MP4。手机测试为桌面 Chromium 窄屏，不代表 iPhone 真机编码测试。

拼图代码：`src/poster.ts` 编排 / 渲染，`src/components/PosterComposer.tsx` 交互。参考仅用于分析构图，未打包参考图或他人作品。

## 统一纸墨与柔网验证（2026-11-18）

- 默认青粉刊物与海报保持相同纸墨及 68% 叠印浓度；两种模式修改浓度后互相同步。使用新的 v5 参数存储，旧 v4 缓存不覆盖新的默认风格。
- 实际下载 1536×1024 图像、1800×2400 海报 PNG；细颗粒和柔网均完成约 6 秒 MP4 导出及 FFmpeg 完整解码。柔网成品 640×426、51 帧、5.94 秒，实际约 8.6 fps。
- 清晰网点仍可独立选择；TypeScript、生产构建通过，浏览器未报 JS 错误。统一配色版在 390×844 视口无横向溢出。
